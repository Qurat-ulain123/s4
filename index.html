HTML

HTML is used to create the structure and content of a webpage. It allows us to add headings, paragraphs, images, links, lists, and other elements.

HTML provides the basic structure that browsers use to display a webpage.

CSS

CSS is used to style webpages. It controls colours, fonts, spacing, layouts, borders, and many other visual properties.

Separating CSS from HTML makes websites easier to manage and update.

Web Development Tools

Modern web development can be done using many different tools. Visual Studio Code provides an environment for writing code, while Live Server makes it easy to test webpages locally.
